# Conversational workspace

Mode: Operate. Scope: authenticated chat home, conversation detail, navigation, composer, message content, files, and sources.

The user comes to ask a medical information question, attach a document where relevant, read a careful response, and return to the same conversation. Keep the existing routes, authentication, chat and file controls, and medical safety language. Sources and file states are shown only from real response data.

## Direction contract

**THESIS:** A calm research desk for health questions. The answer, its supporting material, and the next question form one readable path.

**OWN-WORLD:** A light mineral canvas, deep teal ink for selected actions, dark slate body text, fine cool-gray rules, and quiet off-white surfaces. The existing logo remains product identity. Dark mode uses the same hierarchy in charcoal and muted teal.

**STORY:** Start with an open question. In a conversation, read the assistant response as a document, inspect any actual sources or attached files beside that answer, then continue in the fixed composer.

**FIRST VIEWPORT:** A narrow, collapsible conversation rail at left; one restrained title line above a centered reading column; a plain, prominent question composer below the conversation. On an empty chat the title and prompt suggestions sit in the reading column without a dashboard grid. Signature interaction: numbered citations in an answer jump to the matching source row.
